<table width="100%">
<tr><td width="100%" valign="top">

<div align="center">
  <img src="https://readme-typing-svg.demolab.com?font=JetBrains+Mono&weight=600&size=21&duration=1&pause=999999&color=58A6FF&center=true&vCenter=true&width=700&lines=01+%C2%B7+Macroeconomic+Risk+in+SEC+Comment+Letters" alt="" />
</div>

<sub>
When the SEC writes to a company about its 10-K, does it ask about inflation, interest rates, FX exposure? This measures that — across the full WRDS comment-letter corpus, 2004 onward.
</sub>

<br /><br />

<sub>
Column-projected <b>Parquet</b> reads keep a 300-column dataset inside Colab's RAM ceiling. A single vectorised regex pass tags macro-risk language across eight categories — FX, rates, inflation and input costs, aggregate output, credit and liquidity — with real-estate boilerplate stripped first so <i>"market conditions"</i> in a REIT filing doesn't masquerade as macro commentary. <b>TF-IDF</b> surfaces the vocabulary that actually separates those letters. Output is a year-by-year series of macro-risk incidence against total letter volume.
</sub>

<sub>
Messaging that survives the moment the network doesn't — disasters, blackouts, jammed stadiums, anywhere the towers stop answering.
</sub>

<br /><br />

<sub>
Android devices form an ad-hoc <b>BLE mesh</b> and forward messages hop by hop, no infrastructure required. Payloads are encrypted end to end and decrypted only at the recipient, with keys held in the Android Keystore. A network-selection layer scores signal strength, latency and packet loss to choose between the mesh and an internet relay, falling back automatically as conditions shift. Acknowledgement and retransmission handle the rest.
</sub>
