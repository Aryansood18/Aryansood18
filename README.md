### &nbsp;01 &nbsp;·&nbsp; Macroeconomic Risk in SEC Comment Letters

<sub>
When the SEC writes to a company about its 10-K, does it ask about inflation, interest rates, FX exposure? This measures that — across the full WRDS comment-letter corpus, from 2004 onward.
</sub>

<br /><br />

<sub>
Column-projected <b>Parquet</b> reads keep a 300-column dataset inside Colab's RAM ceiling. A single vectorised regex pass tags macro-risk language across eight categories — FX, rates, inflation and input costs, aggregate output, credit and liquidity — with real-estate boilerplate stripped first so <i>"market conditions"</i> in a REIT filing doesn't masquerade as macro commentary. <b>TF-IDF</b> surfaces the vocabulary that actually distinguishes those letters. Output is a year-by-year series of macro-risk incidence against total letter volume.
</sub>

### &nbsp;02 &nbsp;·&nbsp; Secure Emergency Communication over BLE Mesh

<sub>
Messaging that survives the moment the network doesn't — disasters, blackouts, jammed stadiums, anywhere the towers stop answering.
</sub>

<br /><br />

<sub>
Android devices form an ad-hoc <b>BLE mesh</b> and forward messages hop by hop, no infrastructure required. Payloads are encrypted end to end, decrypted only at the recipient, with keys held in the Android Keystore. A network-selection layer scores signal strength, latency and packet loss to decide between the mesh and an internet relay, falling back automatically when conditions shift. Acknowledgement and retransmission handle the rest.
</sub>
